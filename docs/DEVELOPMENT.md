# ByteDesk 设计与开发记录

## 旅行足迹预览

旅游栏目使用 `TravelJournal.vue`：世界地图、地点详情和下方游记卡片。支持双语与深浅主题、拖动、加减缩放、键盘方向键/+/-/Home、双指缩放、世界复位与足迹定位。普通滚轮保留页面滚动，⌘/Ctrl + 滚轮缩放地图；卡片的“在地图上查看”回到地图定位。邻近地点随缩放聚合，同地点可关联多篇游记；没有坐标的文章仍显示在下方。

游记 frontmatter 可选 `place: { id, name, region, longitude, latitude }`，地点名称随文章语言本地化，坐标范围由内容 schema 验证。目前仅有一个“多洛米蒂”示例地点，关联已有示例文章，不代表站长的真实足迹。

地图使用约 179 KB 的 Natural Earth 矢量坐标，不是位图，照片继续从 R2 读取。无需地图账户、API Key 或在线瓦片请求。这版是旅行概览地图，没有省市街道底图；来源见 `ASSET_CREDITS.md`。

收尾修复：标签筛选后自动显示可见地点，地址同步当前标签；地点详情列出对应游记链接，重叠地点可从展开的列表逐个选择；标记尺寸按 SVG 实际缩放计算。照片加载失败时显示占位与重试入口，地图仍可操作。已用本地测试数据核对多地点、同地点多篇游记、无坐标、无匹配标签和图片失败，并检查 320/390 像素窄屏、英文页面与深浅主题；尚未进行手机真机手势测试。

个人程序员博客。中文标语：记录代码，也记录灵感。英文标语：A home for code and ideas.

## 产品方向

采用 macOS 桌面风格与极简文章排版。展示技术文章、项目、图文日常、短记和个人介绍。第一版支持中文与英文切换，中文为默认语言。

内容主要分为四个方向：宠物（Pets）、日常（Daily）、旅游（Travel）、代码（Code）。图片目录使用对应的英文名称，日常照片由中英文内容共用；含界面文字的应用展示图按语言分别保存。

## 已讨论的设计建议

- 午夜蓝渐变壁纸、浅色内容窗口、冰蓝强调色、半透明 Dock、柔和阴影、红黄绿窗口按钮。
- 默认打开文章窗口；列表参考 Finder，左侧分类，右侧文章摘要。
- 文章支持最大化阅读、目录、代码高亮与复制。
- 窗口拖拽等交互保持可选；所有内容都可直接点击访问。
- 手机使用简洁全屏布局，保留 macOS 风格元素。
- 支持深浅色模式、搜索、分类与标签、RSS、基础 SEO、sitemap。
- 每篇文章有独立链接，支持刷新、分享及浏览器前进后退。

## 技术选型

已确认使用 Astro + Vue 3 + TypeScript + CSS + Markdown/MDX。用户不熟悉 React，因此交互组件采用 Vue，便于后续维护。

Astro 预生成文章 HTML；通过官方 `@astrojs/vue` 集成，让 Vue 负责窗口、Dock、搜索和图片查看等交互。Vue 组件使用单文件组件（`.vue`）、组合式 API 和 `<script setup lang="ts">`。文章默认使用 Markdown，确有嵌入组件的需要时再使用 MDX。开发时核实各依赖的当前稳定版本与兼容性，并通过锁文件固定版本。

文章存入项目，使用 Git 管理；提交后自动构建发布。已确认：文章配图和日常照片存入 Cloudflare R2，网站图标等界面资源随项目管理。第一版暂不规划数据库、登录、评论、点赞或网页写作后台，这些尚未做最终需求确认。

## 图片存储

- 使用 Cloudflare R2 标准存储。用户预计图片量较少，不要求为节省空间手动压缩；后续可自动生成适合屏幕尺寸的展示版本，并保留原图入口，具体处理流程待实现。
- 文章通过图片地址引用 R2 内容；正式上线时优先绑定图片子域名，具体域名待定。
- R2 有免费额度，超过额度按用量计费；用户已在 Cloudflare 控制台完成开通。
- 2026-09-08 已创建并查询确认图片桶 `bytedesk-images`，存储类型为 Standard，自动分配位置为 WNAM。现已开启公开读取并上传示例照片与 Zoji 展示素材，图片自定义域名尚未配置。

2026-09-08 已在 R2 控制台创建并核实以下四个顶层目录（零字节目录标记）。上传时再按年份及一次分享的主题建立子目录。

```text
bytedesk-images/
├── pets/       # 宠物：照片、成长记录、有趣瞬间
├── daily/      # 日常：生活、美食、随手拍
├── travel/     # 旅游：按每次行程整理
└── code/       # 代码：技术文章截图、示意图、项目演示图
```

路径格式为 `<分类>/<年份>/<日期-主题>/<文件名>`。例如 `travel/2026/2026-10-01-city-walk/01.jpg`，仅为命名示例，不代表真实行程。代码配图也可按文章主题归档，例如 `code/2026/astro-blog/setup.png`。使用简短英文、数字和连字符，避免空格；每次分享独立一个目录，防止同名图片被覆盖。

## 多语言

已确认：第一版支持中文与英文切换。

- 导航、分类、按钮、搜索提示及其他界面文案集中管理，提供中英文版本。

- 记住用户的语言选择；具体内容可逐步补充译文，不默认自动翻译或发布全部内容。

## 主题切换

已确认：第一版支持主题切换。当前按以下方案设计：

- 提供浅色、深色、跟随系统三种模式，首次访问默认跟随系统。
- 记住用户选择，刷新页面或再次访问后仍然生效。
- 桌面壁纸、窗口、Dock、文章正文和代码块统一适配主题，保证文字清晰可读。
- 手机端同样提供语言和主题切换入口；语言与主题可独立选择。

### 太阳系桌面（2026-09-08）

默认壁纸改为 Three.js 太阳系：太阳粒状表面与日冕、八颗行星、月球、土星环、地球大气层、小行星带和银河星空。表面全部由程序着色器生成，无新增位图、外部纹理或 R2 请求。距离、尺寸、公转速度及地表为艺术化表达，不用于天文测量。

「壁纸 / Wallpaper」菜单可以收起窗口欣赏太阳系、暂停/继续运行、切回经典壁纸。壁纸与暂停偏好保存在 localStorage，模拟时间在当前标签页刷新和页面跳转后续接。正常阅读时窗口保持原来的行为，深浅主题只改变界面，宇宙保留独立的光照。移动端采用纵向轨道构图。

`SolarWallpaper.vue` 动态导入 `solarScene.ts`，表面着色器在 `solarShaders.ts`。桌面欣赏时目标 30 fps，窗口打开时目标 16 fps；画布最多约 200 万像素。窗口全屏、标签页隐藏时停止渲染，系统减少动态效果时呈现静态场景。切换壁纸和组件卸载会释放 GPU 资源、事件与观察器；WebGL 不可用时显示静态宇宙配色。

验证：类型检查 0 错误 / 0 警告，生产构建 38 页，13 项测试通过；浏览器检查了中英文菜单、深浅主题、暂停/恢复、全屏时暂停与退出恢复、切回经典壁纸后的画布释放，以及 390px 纵向构图和 320px 英文菜单无横向溢出。Three.js 共享资源块仍有超过 500 kB 的构建提醒。
